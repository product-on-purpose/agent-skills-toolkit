02

Executive summary

acme-content-skills is a healthy, genuinely cross-agent library that has cleared the multi-agent bar and now sits one well-scoped push away from the self-proving Gold tier.

The library was evaluated against all 30 deterministic checks of the Advanced Skill Library Standard, alongside an advisory behavioral pass (each skill run against its triggering eval set) and a qualitative review of scoping and chain design. The verdict is unambiguous: it earns Silver (Convergent). Its twelve skills, two subagents, and one command are portable and self-describing, carry a consistent acme- prefix, declare both claude and codex as targets, and emit clean per-agent manifests from a single canonical library.json. The deterministic gate returns exit code 0 at the declared tier.

Two Bronze-level warnings surfaced, neither of which gates the build. One skill description (acme-content-calendar) scores 0.62, below the 0.70 quality bar, because it states neither a concrete action nor a use-when trigger. One skill body (acme-write-blog-post) runs to roughly 240 instructions, over the ~200 guidance, which risks later steps such as its SEO pass being silently dropped at runtime. Both are quick to close and worth closing, but they are advisory only and do not affect the tier earned.

Gold is blocked by exactly three checks, and all three are structural scaffolding rather than capability gaps. There is no continuous-integration workflow that runs the portable gate, so the library cannot yet prove itself in CI (G2). Two of its three chain edges have no regression eval, so a change to acme-style-critic could silently break the writing skills that delegate to it (G3). And there is no curated RELEASE-NOTES.md distinct from the technical changelog (G5). The hard part - cross-agent emission, clean chain contracts, drift-free generated docs - is already done.

Recommended next move: run the three Gold-blocker prompts in the Improvement path in order (CI first, then the two chain evals, then release notes), and re-evaluate. That promotes the library to a self-proving Gold reference without editing a single skill's behavior. Optionally, fold in the two warning fixes for a clean sweep.

How to read this report

Read top to bottom; nothing is hidden behind tabs or expanders. Section 05 is the evidence ledger - one row per check, all thirty itemized, with a "why it matters" note in the margin for every non-pass. Section 07 gives a copy-paste prompt for each gap that you can hand straight to your agent. The status legend lives in section 04 and again in section 10.

A quick gloss on the tiers: Bronze means portable and self-describing on any agentskills.io agent; Silver means it converges cleanly across every declared agent; Gold means it is self-proving - it builds, checks, documents, and releases itself.

Methodology & scope

Three layers, kept strictly separate so the verdict stays honest. Only one of them decides the tier.

  • Deterministic conformance - decides the tier. The portable Node gate runs all 30 checks (U1-U12, S1-S8, G1-G10) with real exit codes and no model in the loop. This is the only layer that decides a pass or fail, and the only layer that determines the tier earned.
  • Behavioral - advisory. Each skill is run against its triggering eval set to confirm it fires when it should and stays quiet when it should not. Surfaced as evidence, never as a gate result.
  • Review - advisory. A qualitative human-style pass over scoping, descriptions, and chain design. Surfaced as evidence, never as a gate result.

Confidence & limitations

Conformance findings are exact and reproducible: re-run the gate and the same 30 results return. Behavioral and review findings reflect judgment over sampled cases and should be read as evidence, not as a grade.

Three checks pass vacuously here, and the report marks them N/A rather than green: G1 (hook documentation) and G6 (deprecation policy) because the library ships no hooks and deprecates nothing yet, and U11 (MCP validation) because the library ships no MCP servers. A vacuous pass is honest about having nothing to check; it is not evidence of a capability.

What each tier guarantees

Bronze - Universal

Portable and self-describing on any agentskills.io agent. Valid manifest, anatomy, frontmatter, and naming; clean references; honest budgets.

Silver - Convergent

Converges cleanly across every declared agent. Consistent prefix, mirrored index, sound chain contracts, complete per-target emission.

Gold - Advanced

Self-proving. The library builds, checks, documents, and releases itself: CI runs the gate, chains carry regression evals, docs and notes are curated.

08

Insights

Qualitative observations and strategic notes that sit beyond the pass/fail of the gate.

01

One CI file from Gold.

The hard part - genuinely cross-agent emission and clean chain contracts - is already done. The remaining gaps are lifecycle scaffolding, not capability. This library is closer to best-in-class than its current Silver grade suggests, and the path there is short and mechanical.

02

Descriptions are the soft spot.

Only one description trips the bar, but several sit in the functional-yet-generic band. A pass with askit-build-skill improve mode would lift triggering reliability across the whole set, which is exactly where the behavioral pass shows late fires originating.

03

The style-critic chain is the spine.

Both writing skills delegate to acme-style-critic, making it the highest-leverage place to add eval coverage for G3. The two missing cases protect the two most-used flows at once, so closing G3 buys more safety than its effort estimate implies.

04

Documentation is already Gold-grade.

Folder READMEs, source docblocks, the Diataxis docs tree, and the docs frontmatter taxonomy (G7-G10) all pass. The library out-documents many libraries that have already reached Gold; the only thing it is missing on that front is the curated release surface.

05

A Claude-only delegation layer is a deliberate, sound choice.

Both subagents target Claude only, which is correct: Codex ingests skills but not subagents. The skills that delegate to them still emit for both agents and degrade gracefully on Codex, so the convergence guarantee holds without forcing a subagent shape onto an agent that has none.
